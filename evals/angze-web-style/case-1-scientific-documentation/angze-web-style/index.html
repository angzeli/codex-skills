Moleculum

Moleculum is a Python toolkit for preparing, running, and analysing atomistic simulations. It provides a consistent interface to classical and first-principles engines while keeping structures, parameters, units, and provenance explicit.

System overview / 00

Reproducible simulations, from structure to observables.

The toolkit treats a calculation as a traceable scientific sequence rather than a collection of disconnected input files. Structures, methods, execution, and analysis remain explicit at every boundary.

Principle 01

Engine-independent

Move between LAMMPS, CP2K, Quantum ESPRESSO, and local Python calculators without rewriting the workflow.

Principle 02

Unit-aware

Validate dimensional quantities at input boundaries and serialize them with every recorded result.

Principle 03

Provenance-first

Capture code versions, parameters, structure hashes, and runtime metadata in portable run records.

Setup / 01

Installation

Install Moleculum in a dedicated environment. The base package includes structure handling, workflow orchestration, analysis, and the reference Lennard–Jones calculator.

Preparation / Python environment

Install the core package

Python 3.10–3.13 
$ python -m venv .venv
$ source .venv/bin/activate
$ python -m pip install moleculum

Optional backends

External simulation engines are not bundled. Install the relevant adapter, for example moleculum[cp2k], and configure the executable path in your run profile.

Verification command

moleculum doctor
  • Python 3.12.4 — OK
  • Core data directory — OK
  • Reference calculator — OK

Quickstart / 02

Your first calculation

Optimize a water molecule with the bundled reference potential. Each stage returns an immutable object, so the original geometry and calculation inputs remain available for comparison.

Stage 01 / Define

Structure

Construct a molecular system from symbols and Cartesian coordinates. Coordinate units are required.

from moleculum import Structure, units

water = Structure(
  symbols=["O", "H", "H"],
  positions=[
    [0.000,  0.000, 0.000],
    [0.758,  0.000, 0.504],
    [-0.758, 0.000, 0.504],
  ] * units.angstrom,
)
Validated structure

Stage 02 / Calculate

Optimize geometry

Attach a calculator and pass explicit convergence criteria to the optimizer.

from moleculum.calculators import ReferenceLJ
from moleculum.optimize import minimize

calculator = ReferenceLJ(cutoff=8.5 * units.angstrom)
result = minimize(
  water,
  calculator=calculator,
  force_tolerance=0.02 * units.eV / units.angstrom,
  max_steps=200,
)
Converged result

Stage 03 / Inspect

Record outputs

Results contain the final structure, trajectory, observables, and a complete provenance record.

print(result.converged)        # True
print(result.energy.to("eV"))  # -0.317 eV
result.write("runs/water-opt.mrun")

Mental model / 03

Core concepts

Four typed objects define the boundary between scientific intent, numerical execution, and durable evidence.

Object / Geometry

Structure

An immutable collection of atoms, positions, cell vectors, boundary conditions, and per-atom metadata. Transformations return new instances and retain parent identifiers.

Structure(symbols, positions, cell=None, periodic=False)

Protocol / Evaluation

Calculator

A backend that maps a structure and method settings to energies, forces, stresses, or electronic properties. Calculators declare capabilities before execution.

Calculator.evaluate(structure, properties)

Artifact / Provenance

Run record

A self-describing result bundle containing inputs, outputs, logs, environment metadata, and content hashes. Records can be queried without the original backend.

RunRecord.open(path)

Value / Dimension

Quantity

A numerical value with an explicit physical dimension and unit. Compatible units convert automatically; incompatible arithmetic raises a dimensionality error.

Quantity(value, unit)

Validation gate / Coordinate shape

Coordinate convention

Positions use row-major Cartesian coordinates with shape (n_atoms, 3). Fractional coordinates must be converted with structure.from_fractional(...).

Execution model / 04

Computational workflow

A workflow is a directed sequence of typed tasks. Moleculum validates dependencies before submission, isolates each task in its own run directory, and resumes only from verified outputs.

01

Prepare

Structure + method

02

Validate

Units + capabilities

03

Execute

Local or scheduler

04

Analyse

Observables + record

Typed dependencies

Engine / Directed workflow

Silicon relaxation and bands

Profile: slurm-cpu 
from moleculum.workflow import Workflow

workflow = Workflow("silicon-relaxation")
relax = workflow.add(
  "relax", task="geometry_optimization",
  structure="silicon.cif", calculator="cp2k/pbe-d3",
)
workflow.add(
  "bands", task="band_structure",
  structure=relax.output.structure, path="G-X-W-K-G-L",
)
workflow.run(profile="slurm-cpu")

Runtime evidence / Active

Ready → Running

  • ready — inputs validated; dependencies satisfied
  • running — backend process is active

Runtime evidence / Terminal

Complete → Failed

  • complete — outputs passed structural validation
  • failed — execution or validation ended with an error
