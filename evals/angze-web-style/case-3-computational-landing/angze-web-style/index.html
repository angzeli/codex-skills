01 / Overview

One consistent record across different scales of chemistry.

Computational projects often fragment into hand-edited structures, engine-specific input files, scheduler scripts, and one-off notebooks. TesseraChem treats these as connected stages in a single scientific record.

The package does not hide the underlying methods. It validates explicit parameters, writes native engine inputs, captures the exact runtime context, and returns analysis-ready data with a traceable origin.

Explicit
Methods, units, and convergence criteria are declared.
Composable
Small tasks connect without locking data to one engine.
Auditable
Inputs, versions, logs, and derived outputs remain linked.

A practical toolkit for the full calculation lifecycle.

Use only the layers you need. Each module exposes stable Python objects and writes ordinary, documented files.

A pipeline that exposes every scientific decision.

Stages exchange versioned artifacts, not implicit session state. Stop, inspect, replace, or reproduce any stage independently.

05 / Technical architecture

A small core, explicit adapters, ordinary data.

TesseraChem separates scientific intent from engine syntax and execution infrastructure. No proprietary database or hosted service is required.

Interface

CLI · Python API · notebooks

User-facing specification and inspection.

Scientific model

Structures · methods · tasks · results

Typed objects with units and validation.

Workflow engine / shared abstraction

DAG resolution · cache · provenance

Deterministic orchestration and identity.

Adapters

ORCA · CP2K · Quantum ESPRESSO · ASE

Native input writers and output parsers.

Execution

Local · Slurm · PBS · containers

Portable runtime and resource policies.

Validated architecture contract

Portable inputs and inspectable outputs

  • Interoperable — XYZ, CIF, JSON, YAML, CSV, Parquet, HDF5
  • Testable — Dry-run planning and schema validation before execution
  • Portable — Lockable environments and container-aware manifests
  • Extensible — Documented adapters for new engines and analyses

07 / Publication & citation

Methods belong beside the results.

When TesseraChem contributes to published work, cite the software release, its methods paper, and the underlying electronic-structure engines. Generated citation metadata lists the versions actually used by a run.
